# Управление AirBase

Используй инструменты AirBase MCP и выбранную пользователем проектную базу. Перед изменением прочитай схему нужной таблицы и точные записи. Не угадывай ID, коды полей, ссылки между записями и допустимые значения.

## Записи и ячейки

- Для одиночной ячейки используй `shd_airbase_update_cell`; для нескольких ячеек — `shd_airbase_bulk_update_cells` с полным списком `record_id`, `field_id` и новых `value`.
- Для создания и обновления записей проверяй значения через `shd_airbase_validate_records`. Для массового создания или upsert сначала запускай соответствующий инструмент с `dry_run=true`, разбирай конфликты, затем выполняй запись только в рамках запроса пользователя.
- Массовое изменение ячеек не имеет dry-run. До вызова сверь каждую целевую запись и ячейку с текущими данными и запросом пользователя.
- Не удаляй записи, поля или таблицы и не отсоединяй внешнюю таблицу без явного запроса и требуемого `confirm=true`.

## Схема и доступ

- Для действий схемы используй `shd_airbase_action` и передавай конкретное действие, параметры и payload из прочитанной схемы. Проверяй зависимости поля через `field-usages` перед потенциально ломающим изменением.
- Для правил доступа к полю сначала прочитай `get-field-access-policy`; сохраняй только явно запрошенные `default_level` и правила.
- Подключай внешнюю таблицу только по предоставленному пользователем `source_url`. Перед отключением уточни конкретную таблицу и используй подтверждение.
- Для доступа клиентов по публичной ссылке сначала прочитай текущие настройки; режим `selected` должен содержать только перечисленные пользователем таблицы.

## Импорт и вложения

- Перед CSV/TSV импортом всегда используй preview и сверяй целевую таблицу, поля и количество строк.
- Для скачивания или миниатюры передавай attachment `src`, а также `record_id` и `field_id`, чтобы сервер проверил доступ к вложению.
- Не используй AirBase-инструменты для Omni или System Base.

После записи кратко сообщи, какие сущности изменены и какие серверные значения вернулись. Отделяй ответ API от предположений и не заявляй, что данные изменены, если инструмент вернул ошибку или не подтвердил сохранение.
